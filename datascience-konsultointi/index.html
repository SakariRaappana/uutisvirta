Tärkeimmät uutiset

Foundry hosted agent isolation with Microsoft Agent Framework

Microsoft on ottanut merkittävän askeleen agenttien hallinnassa julkaisemalla uuden Foundry-hosted agenttien eristämisominaisuuden Microsoft Agent Framework -alustalla. Tämä parannus mahdollistaa agenttien eristämisen Foundry-hostatuissa ympäristöissä, mikä tarjoaa parantunutta tietoturvaa ja suorituskykyä. Agenttien eristäminen tehdään Agent Session Pooling -tekniikalla, joka lisää tehokkuutta ja vähentää ristiriitoja yhteisissä ympäristöissä. Tämä on erityisen tärkeää tiimeille, jotka hallinnoivat useita samanaikaisia agentteja saman alustan alle. Uudistuksen myötä kehittäjät voivat yksinkertaisesti määritellä eristyksen tason agenttien välillä, mikä auttaa ennakoimaan mahdollisia tietoturvaongelmia ja parantamaan kokonaisvaltaista toimivuutta.
